# Hier entstehen die einzelnen Websites

Pro Auftrag ein Ordner `kunde-name/`, erzeugt durch Kopieren von `template/`.
Jeder Ordner braucht eine eigene `DOCTRINE.md` mit genau einem Wort: `taste` oder `impeccable`.

Beim Kopieren wird `QA.md` **geleert**, nicht mitgenommen. Eine kopierte QA traegt die Zahlen
des Geruests und sieht aus wie eine Messung dieser Seite.
